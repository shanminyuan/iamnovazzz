# Nova Zhang — A little world

An interactive personal website built with HTML, CSS and JavaScript.

Live website: https://shanminyuan.github.io/iamnovazzz/

## Publish

GitHub Pages serves the root folder of the `main` branch. The `.nojekyll` file
keeps the site as plain static files; no install or build step is needed.
New pushes to `main` update the website automatically after Pages finishes deploying.

## Preview locally

Run `python3 -m http.server 8765` in this folder, then open http://localhost:8765/.

## Pages

- Home: keepsake tin with an animated opening
- Experience
- Product portfolio
- Favourite books
- Contact
- Interests

All images, fonts and background music are served from the `assets` folder.
The homepage includes a flat resting cover for mobile browser compatibility.
